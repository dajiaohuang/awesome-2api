# Security policy

This repository is an index of public references. It must not contain account
credentials, session cookies, private API keys, personal data, or unpublished
endpoints.

Please open a private report through GitHub if you find a secret committed to
this repository. For ordinary stale links or incorrect metadata, open a normal
issue or pull request and include the public evidence needed to verify the
change.

The list does not endorse bypassing authentication, quotas, payment controls,
or a service's terms. Use each referenced project only with authorization.
